What it does

One thing, done well: switching resolution without opening System Settings.

🖥️

Every display, one menu

Lists the built-in and external displays, with the current resolution checked and the most common resolutions one click away.

↔️

Ultrawide included

2560x1080, 3440x1440, 3840x1600 and 5120x1440 are on the list. Those the connected display does not support are shown disabled.

🔍

Hidden HiDPI modes

Shows the scaled resolutions macOS does not present by default in Settings → Displays.

⏱️

Automatic revert

After a change, a 15-second countdown asks for confirmation. With no answer, it returns to the previous resolution, like macOS itself.

✏️

Rename a display

Saves a name of your choice at system level, visible in Settings → Displays. It asks for the administrator password through the macOS dialog.

🔒

100% local

It makes no network requests and has no account or telemetry. The code is open.

Udjath only shows resolutions macOS considers supported by the connected display. It does not force modes the monitor does not advertise.

Install

Apple Silicon and Intel.

Download

Download Udjath-0.1.0.zip, unzip and drag Udjath.app to Applications.

First launch

The app is not notarized: macOS shows “Udjath Not Opened”. Click Done, go to System Settings → Privacy & Security → Security → Open Anyway.

Use

The eye appears in the menu bar (the app has no Dock icon). Click it and choose the resolution.

Uninstall: quit the app from its menu and drag it to the Trash.
